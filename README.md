# আজিজ আর্মি জেনারেল স্টোর

Next.js 14 + MongoDB + Cloudflare R2 — পণ্য, স্টক, বাকির খাতা, ড্যামেজ ও উত্তোলনের হিসাব।

## চালানোর নিয়ম
1. `npm install`
2. `.env.example` কপি করে `.env.local` নাম দিন, ভ্যালুগুলো বসান (`.env` নয় — `.env.local`)
3. `npm run dev` → http://localhost:3000
4. `.env.local`-এর ADMIN_PHONE / ADMIN_PASSWORD (৬ অক্ষর) দিয়ে লগইন করুন — প্রথমবারেই অ্যাডমিন তৈরি হবে
5. অ্যাডমিন প্যানেল থেকে বিক্রেতা/ক্রেতার অ্যাকাউন্ট বানান

## R2 সেটআপ
- Bucket বানিয়ে Public access (r2.dev) চালু করুন, CORS লাগবে না (আপলোড সার্ভার থেকে হয়)
- API Token (Object Read & Write) নিয়ে `.env.local`-এ বসান

## Vercel ডিপ্লয়
Environment Variables-এ `.env.local`-এর সব ভ্যালু দিন।

## নতুন সংযোজন (v2)
- ড্যাশবোর্ড: বিক্রি, আনুমানিক লাভ, আদায়, ড্যামেজ ক্ষতি, গ্রাফ, মোট বাকি, মেয়াদোত্তীর্ণ বাকি, স্টক কম/শেষ, মেয়াদ শেষ হচ্ছে
- স্টক কম সতর্কতা (পণ্যে `minStock`), মেয়াদ কাছাকাছি ব্যাজ
- মেমো ও স্টেটমেন্ট প্রিন্ট, WhatsApp/SMS তাগাদা, কল বাটন
- বিক্রি/পরিশোধ মুছলে (অ্যাডমিন) স্টক ও হিসাব ঠিক হয়ে যায়
- CSV এক্সপোর্ট (পণ্য, বাকি, উত্তোলন), পাসওয়ার্ড পরিবর্তন, PWA (ফোনে ইনস্টল)

## ভাষা ও থিম (v3)
- হেডারে **EN / বাং** বাটনে ভাষা (বাংলা ↔ ইংরেজি) এবং ☀️/🌙 বাটনে লাইট ↔ ডার্ক মোড বদলানো যায়
- দুটো পছন্দই কুকিতে সেভ থাকে, তাই পরের বার ঢুকলেও একই ভাষা ও মোড থাকে
- সংখ্যা ও তারিখ বেছে নেওয়া ভাষা অনুযায়ী দেখায় (বাংলা অঙ্ক / ইংরেজি অঙ্ক), মেমো ও CSV-ও একই ভাষায়
- নতুন লেখা যোগ করলে `t('বাংলা লেখা')` দিয়ে মুড়ুন, আর `lib/en.json`-এ `"বাংলা লেখা": "English text"` যোগ করুন
- ডেটাবেসের তথ্য (পণ্যের নাম, ক্রেতার নাম ইত্যাদি) অনুবাদ হয় না, আপনি যেভাবে লিখেছেন সেভাবেই থাকে
